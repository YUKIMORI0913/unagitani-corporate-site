# Company Information 確認待ち

以下はデータ項目を用意していますが、正式資料で確認できていないため本番画面・構造化データには表示しません。

- 資本金
- 法人番号（13桁）
- 従業員数
- 主要取引銀行（京都銀行、京都中央信用金庫を掲載可能か確認）
- 適格請求書発行事業者登録番号（T + 13桁）
- 主な取扱メーカー

## 公開前に代表者確認が必要な事項

- 2025年9月期売上高実績「約5.0億円」の表記精度
- 2026年9月期売上高見込み「約11〜12億円」
- Privacy Policyの制定日と実際の個人情報取扱運用
- Complianceページの各方針と実務の一致
- GearLoopの名称および「開発中」表示

2026年9月期の見込み値は `reviewAfter: "2026-10-31"` を設定し、`scripts/check_forecasts.py` で期限超過を検知します。
