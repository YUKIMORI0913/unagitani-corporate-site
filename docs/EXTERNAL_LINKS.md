# 外部プロフィールのリンク統一（コピペ用）

新規ドメインに外部からのリンクが1本もないことが、インデックス登録が進まない
原因の一つです。ここに貼り付ける文面をまとめます。各サービスの本人アカウントで
作業してください。

置き換える対象の旧URL:

```
https://unagitanibass.wixsite.com/official
```

## 1. 鰻谷饅頭サイトへのリンク

プロフィールのURL欄・リンク欄に、次を設定します。

```
https://manju.unagitani.com/
```

| サービス | 設定する場所 |
| --- | --- |
| Instagram `@bass.you` | プロフィールを編集 → ウェブサイト |
| X `@unagitani_913` | プロフィールを編集 → ウェブサイト |
| YouTube `@manjuunagitani7643` | チャンネルをカスタマイズ → 基本情報 → リンク |
| Bandcamp | Profile → Edit profile → Website |
| TuneCore Japan アーティストページ | アーティスト情報 → 公式サイトURL |

リンクのテキストを設定できる場合は次を使います。

```
鰻谷饅頭 Official Site
```

## 2. コーポレートサイトへのリンク

各ECモールの店舗情報欄に、次をそのまま貼り付けます。既存の返品・送料・支払方法
などの記載は各店舗のものを残し、以下の項目だけ追記・修正してください。

```
商号          株式会社UNAGITANI
代表者        代表取締役 森 佑紀
所在地        〒600-8223 京都府京都市下京区七条通油小路東入大黒町227番地 第2キョートビル402
電話番号      050-3635-6294
古物商許可     京都府公安委員会 古物商許可 第611262630020号
公式サイト     https://corporate.unagitani.com/
```

| 掲載先 | 設定する場所 |
| --- | --- |
| Amazon | セラーセントラル → 設定 → アカウント情報 → 出品者プロフィール |
| 楽天市場 | RMS → 店舗設定 → 会社概要・特定商取引法に基づく表記 |
| Yahoo!ショッピング | ストアクリエイターPro → ストア情報 → 会社概要 |

1行で書く欄しかない場合:

```
株式会社UNAGITANI（公式サイト: https://corporate.unagitani.com/）
```

## 4. 確認

作業後、各プロフィールを未ログインのブラウザ（シークレットウィンドウ）で開き、
リンクが実際に表示されているか確認してください。ログイン中しか見えない欄は
Googleからも見えません。

`nofollow` が付くサービス（Instagram、Xなど）でも、Googleに「このドメインが本人の
公式サイトである」と伝える手がかりにはなります。外してもらう必要はありません。
