# 株式会社UNAGITANI コーポレートサイト 実装計画

作成日: 2026-08-03  
対象: `unagitani.co.jp` 向け静的コーポレートサイト

## 1. 目的と範囲

取引先・メーカー・金融機関・採用候補者に向けて、株式会社UNAGITANIの実在性、信用、成長性、技術力を伝える公式サイトを制作する。商品を販売するECサイトは本プロジェクトの対象外とする。

以下は対象外とする。

- GearLoopのShopifyテーマおよび既存のShopify関連プロジェクト
- UNAGITANI Accounting Engine
- 鰻谷饅頭に関する全ての掲載・制作
- 未確認の実績、売上、取引先、沿革、ニュースの創作
- 問い合わせ送信サービスの契約または外部サービスへの接続

## 2. 技術方針

- 依存関係を持たない静的HTML/CSS/JavaScriptで実装する。
- `index.html` と各ページの `index.html` により、一般的な静的ホスティングで公開可能にする。
- JavaScriptはモバイルメニュー、フォームの未接続案内、アクセシビリティ補助のみに使用する。
- 写真素材は使用せず、必要な箇所は控えめな図形表現または差し替え可能なプレースホルダーとする。
- 共通スタイル、共通スクリプト、メタ情報を再利用し、CMSなしでもページ編集とお知らせ追加がしやすい構成にする。

## 3. ページ構成

1. トップ (`/`)
2. 私たちについて (`/about/`)
3. 事業内容 (`/business/`)
4. 運営ブランド (`/brands/`)
5. 代表メッセージ (`/message/`)
6. 会社概要 (`/company/`)
7. お知らせ一覧 (`/news/`)
8. お問い合わせ (`/contact/`)
9. プライバシーポリシー (`/privacy/`)

## 4. 情報設計・表現方針

- 中心メッセージは「商売を、仕組みで強くする。」「テクノロジーで流通をもっと速く、もっと正確に。」とする。
- 理念候補「速さは価値である。正確さは信頼である。」は仮案として `assets/js/site-data.js` に集約し、画面上には仮案であることを表示しない。公開判断前に `docs/CONTENT_REVIEW.md` で確認する。
- Electric UNAGIは現在運営中のブランドとして表記する。
- GearLoopは「開発中」と明示し、稼働済み・販売済みと受け取れる表現を用いない。
- 鰻谷饅頭は掲載しない。
- 中古品買取・再販は古物商許可に基づく取扱いと将来的な再流通事業の拡大方針を示すに留め、未開始のサービスは稼働中と表現しない。
- 不明情報は画面に推測で掲載せず、`docs/CONTENT_REVIEW.md` に `⚠️ TODO` として集約する。

## 5. デザイン方針

- 白、黒、濃紺を主色、Electric UNAGIを想起させるオレンジをアクセントとする。
- 十分な余白、大きな見出し、明確な情報階層を採用し、落ち着いた企業サイトの信頼感を重視する。
- ダッシュボード、ターミナル表現、数値アニメーション、AIデモ風の演出は使用しない。
- 最小限の動きにし、`prefers-reduced-motion` を尊重する。

## 6. SEO・アクセシビリティ・品質

- 全ページに固有の title、description、canonical、OGP、Twitter Cardを設定する。
- トップページに Organization 構造化データ（JSON-LD）を設定する。
- `robots.txt`、`sitemap.xml`、SVG faviconを用意する。
- 適切な見出し階層、スキップリンク、フォーカス表示、ラベル付きフォーム、十分なコントラストを実装する。
- 公開前にリンク、HTML構造、メタ情報、構造化データを静的検査する。

## 7. 実装手順

1. 基盤（共通CSS/JS、メタ情報、favicon、robots、sitemap）を作成する。
2. 9ページと共通ナビゲーション／フッターを実装する。
3. 未確定事項を `docs/CONTENT_REVIEW.md` に記録する。
4. READMEにローカル確認、公開、更新方法を記載する。
5. ローカルサーバーでPC・スマホの表示を確認し、スクリーンショットを取得する。
6. リンク、表示崩れ、メタ情報、構造化データを検査する。
7. 検査結果と未確定事項を報告し、初回コミットを作成する。
